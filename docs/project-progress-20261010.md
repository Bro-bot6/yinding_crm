## 本地存档

- `archive-crm.pyw` 生成包含数据库、Excel 导出、校验信息及附件（若存在）的 ZIP 存档。
- Windows 任务 `YindingCRMBackup` 每天北京时间 17:30 执行；错过计划时间后在条件满足时补执行。
- 当前电脑存放位置：`E:\yinding_crm\backups\daily`；历史每日存档不自动删除。
- `install-lan-service.ps1` 包含服务、存档和健康检查任务的安装配置。
- 新电脑使用单一检出目录时，脚本默认使用项目下的 `data` 和 `backups/daily`。运行工作目录与共享数据目录分离时，存档任务从共享目录启动脚本，并通过 `--code-dir` 指定运行代码目录。
